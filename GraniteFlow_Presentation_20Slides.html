THE INDUSTRIAL BOTTLENECK

Why Traditional Quarry Block Inspection Breaks Down

Millions of dollars of dimensional granite blocks (Black Galaxy, Kattima Black, River White) are still measured on paper slips in dusty, offline quarry pits.

📝
HIGH ERROR RATE

1. Handwritten & Printed Quarry Slips

Field inspectors record Gross Length, Height, Width, and Allowance (10–20 cm) on physical paper slips. Manual re-keying into spreadsheets causes transposition errors on block numbers and dimensions.

Avg Manual Entry Time 18–25 mins / slip
📐
REVENUE LEAKAGE

2. Gross-to-Net CBM Math Discrepancies

Every granite block requires subtracting allowance from each axis before computing Net CBM: (L_net × H_net × W_net) / 1,000,000. Even a 2 cm misread shifts invoice value by ratusan USD per block.

Unchecked Formula Drift 4.2% of field rows
🚢
CUSTOMS DELAYS

3. Export Document Mismatches

When the Inspection Report, Packing List, and Commercial Invoice have mismatched Block Counts, Total CBM, Port of Discharge, or Consignee names, shipments get held at port customs.

Connectivity at Quarry 0% Cloud Uptime
⚡ Core Challenge: Build an offline-capable mobile app + ML triage system that digitizes slips, validates physics & CBM math, and generates audit-proof PDF export packages.

ON-DEVICE DOCUMENT INTELLIGENCE

MlKitOcrEngine + 3-Strategy GraniteSlipParser

Why standard OCR fails on tabular quarry slips — and how GraniteFlow's cascaded 3-strategy parser achieves 100% structural recovery.

STRATEGY A · ROW-BY-ROW

Horizontal Line Tokenizer

When OCR preserves horizontal line order, Strategy A normalizes delimiters (| , : x X), detects block IDs matching ^[A-Za-z0-9\-_]{2,10}$, and validates physical bounds (L ∈ [40, 700] cm, H,W ∈ [40, 500] cm).

// Row token stream
BG-501 285 145 125 10 → 4.269 m³
STRATEGY B · COLUMNAR RECONSTRUCTION

Vertical Column Zipper

Mobile OCR often reads multi-column tables vertically (all Block IDs first, then a column of Lengths, then Heights, then Widths). Strategy B groups contiguous numeric runs matching blockIds.size() and zips them cleanly!

// Zips vertical columns of length N
IDs[i] + Lengths[i] + Heights[i] + Widths[i]
STRATEGY C · SINGLE-BLOCK CARD

Gross/Net Matrix Extractor

Built for single-block summary cards (like BLOCK NO : 301). Extracts labeled Gross/Net dimensions, parses reported NET CBM, and invokes validateReportedCbmConsistency() automatically.

BLOCK 301: 280×185×185 (-10cm)
→ Verified 8.269 m³

DETERMINISTIC DOMAIN MATH ENGINE

DimensionCalculator.java: Zero-Floating-Point-Drift CBM Math

Uses BigDecimal with RoundingMode.HALF_UP at scale 3 and enforces a strict ±0.005 m³ tolerance against slip-reported volumes.

Core Mathematical Formulas & Tolerance Gate

// 1. Net Dimension Deduction (per axis) Net_L = max(0, Gross_L - Allowance_cm) Net_H = max(0, Gross_H - Allowance_cm) Net_W = max(0, Gross_W - Allowance_cm) // 2. Cubic Meter (CBM) Volume with BigDecimal HALF_UP rawCbm = (Net_L * Net_H * Net_W) / 1_000_000.0; netCbm = BigDecimal.valueOf(rawCbm) .setScale(3, RoundingMode.HALF_UP); // 3. Slip Discrepancy Check (CBM_TOLERANCE = 0.005 m³) if (Math.abs(reportedCbm - calcCbm) > 0.005) { flagWarning("MISMATCHED_CBM_FORMULA"); }
BigDecimal Scale = 3 Tolerance = 0.005 m³ Physical Plausibility Guards

PYTHON MACHINE LEARNING PIPELINE (ml/)

Supervised Extraction-Risk Classification & Quality Triage

Predicts whether an unreviewed OCR measurement row contains subtle extraction errors before a human inspector finalizes the document.

BINARY CLASSIFICATION FORMULATION scikit-learn + joblib
CLASS 0
LOW_OBSERVED_RISK

High probability that OCR dimensions, allowance, and CBM match human-reviewed ground truth.

CLASS 1
NEEDS_REVIEW

High likelihood of misread digits, missing block IDs, or CBM formula inconsistencies.

├── schema/feature_schema.json # 12-column contract v1.0.0

├── src/predict_quality.py # Inference + reason codes

🛡️

Strict Data-Sufficiency Gates (Safe Stop Protection)

Requires ≥ 200 total extracted rows and ≥ 50 rows per class (Class 0 & Class 1). If insufficient data is present, training halts safely with INSUFFICIENT_DATA rather than deploying an unverified model.

🧬

Grouped Holdout Validation (GroupKFold by sourceDocumentId)

All measurement rows from the same physical quarry slip are kept in the same fold so document-level layout characteristics never leak between train and test splits.

💡

Explainable Reason Codes on Every Prediction

predict_quality.py pairs probability scores with human-readable reason codes: MISMATCHED_CBM_FORMULA, EXCESSIVE_ALLOWANCE, INVALID_DIMENSIONS, MISSING_BLOCK_NUMBER.
